What this recording establishes

Exact capability rejection, supervised injection denial, approved research output, memory paging, child scope, scheduler controls and signed audit verification. Dedicated Linux tests separately exercise actual confinement and cancellation.

Verified locally on Apple Silicon / Docker Desktop. The project is a local kernel/API MVP. It makes one initial provider completion; SDK programs drive subsequent actions. It does not claim an autonomous planner or a production multi-tenant boundary.

HUMAN SUPERVISION

A separate door for decisions.

Supervisor and agent APIs use separate keys and Unix sockets. Approval binds the agent, arguments, capability digest and context revision; it cannot widen authority.

LINUX CONFINEMENT

Controls must actually work.

Seven namespaces, Landlock V3, a seccomp allowlist and CPU/memory/PID cgroups. Startup probes disable tools if mandatory enforcement is unavailable.

DURABLE ACCOUNTABILITY

Signed before effects.

Canonical JSONL, SHA-256 chaining, Ed25519 signatures and a signed local checkpoint. Emergency tree cancellation still proceeds when audit storage fails.

RESOURCE CONTROL

Budgets follow the tree.

Children reserve parent budgets and inherit narrower tool scope. Parent termination cancels descendants. Paging and rollback preserve taint and consumed budgets.
