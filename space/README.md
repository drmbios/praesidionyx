# Praesidionyx

An interactive browser demonstration of an operating layer for supervised AI agents.
The playground simulates policy decisions locally. It does not run an LLM, Linux
sandbox, Biscuit verifier or signed audit daemon inside your browser. The Evidence
view replays a credential-safe recording from the real Rust/Linux runtime.

[Full source, quickstart and verification](https://github.com/drmbios/praesidionyx).
No API key, paid inference or sign-in is needed to use this Space.
